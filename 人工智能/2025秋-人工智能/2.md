一、课程简介

人工智能主要研究如何用计算机软件和硬件去实现 Agent 的感知、决策与智能行为，其
理论基础表现为搜索、推理、规划和学习，应用领域包括计算机视觉、图像分析、模式识别、

专家系统、自动规划、智能搜索、计算机博弈、智能控制、机器人学、自然语言处理、社交

网络、数据挖掘、虚拟现实等。本课程作为面向全校人工智能与自动化相关专业的学术型学
位硕士研究生公选课，立足于行为主义人工智能基本观点，以智能 Agent 设计为主线，以 Agent
所处环境特征与任务需求为线索，重点讲授 Agent 在完全可知环境下的搜索技术及规划技术、
未知环境下的推理技术、对抗环境下的博弈技术、随机环境下的不确定推理技术、以及动态

环境下的学习技术等，启发学生学会利用计算机模拟和实现人类智能活动的思维方法，初步

建立系统性的人工智能理论体系，为学生学习智能系统、计算智能、模式识别、自动规划、

智能控制等后续课程奠定基础，并为学生今后从事智能无人系统、机器人、模式识别与智能

系统、任务规划等方向研究打下扎实的基础。在系统回顾人工智能发展历程的基础上，从搜

索与博弈、知识表示与逻辑、不确定性推理、机器学习与神经网络等方面全面阐释人工智能
的核心思想、基本理论，基本方法与典型应用。

二、教学目标

1.  知识和能力目标
通过本课程的学习，使学员掌握人工智能中的基本概念、问题求解智能体、约束满足问

题、博弈问题、基于知识的智能体、智能规划、不确定性知识和推理、机器学习等内容的基

本概念、基本理论与基本方法；为后续开展科学研究和工程应用奠定必要的基础。通过课外

资料阅读、人工智能专题研讨和实验环节的设置，培养学员的科学思维能力、抽象思维能力、
逻辑推理能力、分析问题解决问题的能力、自主学习的能力。

2.  课程思政目标
以集智驭能、立德树人、为战育人为宗旨，将思想政治教育有机融入专业知识教育，实

现知识学习、能力培养、价值塑造同步并进，培养学员严谨的思维方式、求真务实的工作作
风、积极创新的科学精神、献身强军强国事业的情怀。

主要内容：

人工智能的基本概念、基本观点、发展简史、主要研究内容与成就、应用领域和发展趋

势。

2．掌握人工智能的三大学派和四种研究途径的基本观点和关系；

1．Agent 的概念；

3．Agent 任务环境类型及 PEAS 描述方法；

Agent 的定义、Rationality 的含义、PEAS 描述方法；

3.  理解 Agent 的任务环境特征及 Agent 主要类型。

第三章  问题求解 Agent（10 学时）

主要内容：

1．问题求解智能体；
2．问题类型和环境；
3．树搜索、图搜索；
4．启发式；
5．局部搜索和优化方法；
6．约束满足问题；

1．宽度优先搜索策略、深度优先搜索策略；
2．一致代价搜索算法、贪婪搜索算法、A*搜索和启发式搜索算法；
3．局部搜索算法、约束满足问题原理；
4．minimax 搜索算法、-剪枝算法；
教学要求：

1．  熟悉问题求解 Agent 设计方法和问题的形式化；
2．掌握宽度优先搜索策略、深度优先搜索策略的基本搜索算法原理；

4．掌握局部搜索算法原理及内涵、掌握约束满足问题概念及原理；

第四章  逻辑 Agent（6 学时）

主要内容：

1．逻辑 Agent 的基本概念和特征；
2．逻辑推断与逻辑推理的概念和差别；
3．命题逻辑的语法、语义，命题逻辑的前向推理算法、反向推理算法和归结原理；
4．一阶逻辑的基本概念和语法及语义；
5．一阶逻辑的前向链、反向链和归结推理方法；
教学重难点：

1．命题逻辑的语法、语义，命题逻辑的前向推理算法、反向推理算法和归结原理；
2．一阶逻辑的基本概念和语法及语义、一阶逻辑的前向链、反向链和归结推理方法。
教学要求：

1．掌握逻辑 Agent 的基本概念和特征，理解与问题求解智能体的异同；
2．掌握逻辑的基本知识，了解逻辑推断与逻辑推理的概念和差别；
3．掌握命题逻辑的语法、语义，命题逻辑的前向推理算法和归结原理，了解反向推理算

法的基本思想；

4．掌握一阶逻辑的基本概念和语法及语义定义，具备使用一阶逻辑进行问题描述的能力，

掌握一阶逻辑的前向链、反向链和归结推理方法。

第四章  规划 Agent（6 学时）

主要内容：

1．智能规划问题的基本范畴、概念；
2．规划语言 STRIPS；
3．偏序规划算法；
4．基于状态空间搜索的规划问题求解基本原理（前向搜索、后向搜索）；
5．图规划算法；
教学重难点：

1．STRIPS 语言、规划算子，描述规划问题的语言和基本方法；
2．偏序规划算法的基本思想和流程、基于状态空间搜索的规划基本原理（前向搜索、后

向搜索）；

3．图规划算法，不确定、不可知、不可观任务环境下的三种规划问题及规划方法。
教学要求：

1．了解人工智能中研究的智能规划的基本范畴、概念；
2．掌握规划语言 STRIPS、PDDL 描述规划问题的基本方法，并使用规划器进行求解；
3．掌握基于状态空间搜索的规划问题求解基本原理（前向搜索、后向搜索）；
4．掌握偏序规划方法，并能够在简单实例中运用偏序规划算法；

四、教学方式方法建议

（一）课程理念
研究生阶段的教育目标是使研究生形成具有个性化的研究品格、研究定向和研究视野，

以具有独立思考并获得独创研究成果的能力。人工智能在 60 余年的发展历程中不断自我否
定、曲折前行，内涵不断拓展、知识体系快速更迭、技术发展持续演进、应用领域全面扩张，

这也决定了《人工智能》研究生课程具有多学科交叉融合以及综合性、实践性、前沿性、创

新性强的特点，是践行素质教育，培养学生科学思维、创新精神和实践能力的极好载体。教

学过程中秉承“学以致用、知行合一、寓研于教、学研贯通”理念，按照“强化理论基础、

拓展最新成果、贴近工程应用、优化实验环节、完善考核模式”的思路开展教学，将学生能

力素质培养要求具体落实到知识获取能力、学术交流能力、实践创新能力、团队协作能力、

文献阅读与综述能力、学术论文撰写能力等方面上来。

（二）教学方式方法与思路
在上述课程理念的指导下，提出“强化理论基础、拓展最新成果、贴近工程应用、优化

实验环节、完善考核模式”的教学思路。

在教学实施前制定统一的教学大纲，规定教学进度和基本的教学内容。针对不同专业、

不同对象的学生，鼓励在补充内容和题材上有所取舍，以增加课程的信息量，提高学生的学

习兴趣与积极性。

在课堂上主要讲授理论方法的起源与发展、前沿方法与应用、军事案例与发展前景等，

及时与学生开展讨论分析。

课程的教学模式主要为课堂讲授，多媒体教学与软件演示为主。鼓励教员开展教学改革

与教学研究，参加研课、赛课、走课、教学观摩等活动，综合采用传统式教学、启发式教学、

案例式教学、研讨式教学、线上线下混合式教学等多种形式。

教学过程中注意由浅入深、循序渐进，力求呈现教学内容完整脉络。通过讲解军事应用

案例，培养学员应用本课程所涉方法解决相关实际问题的能力。

鼓励教员结合自身经验与体会，灵活使用现代化教学技术与设备，精心制作多媒体课件。

在课程教学中采取多种组织形式开展思政教育，坚定学员献身国防的信心，培养学员严谨的

思维方式、求真务实的工作作风、积极创新的科学精神、献身强军强国事业的情怀。

在考评环节上改变以往“一考定胜负”的做法，将课程考核方式调整为“笔试（50%）+
文献阅读（10%）+专题研讨（10%）+实验（30%）”。笔试从闭卷考试改为开卷考试，使学
生的主要精力从应付考试向轻松学习、研读论文、实践创新、写作训练方向转移。引入专题

研讨、课堂辩论、主题演讲、课程设计、文献综述、实验创新、博弈竞赛等多种方式评价学

生平时成绩，同时进一步规范了各个环节评价标准。

五、课程考核

考核方式：形成性考核和终结性考核相结合。
组织方式：终结性考核为课终考试，采用开卷笔试方式
成绩评定：百分制
记分标准：终结性考核占 50％，文献阅读 10%，专题研讨占 10%，实验占 30%。
