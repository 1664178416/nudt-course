## Implementation approach

我们将采用原生JavaScript结合HTML5和CSS3来实现这个2048游戏，不依赖复杂框架以保持简单轻量。

**核心难点与解决方案：**
1.  **游戏逻辑与状态管理**：使用纯JavaScript实现网格模型与移动合并算法，确保逻辑正确性。通过一个`Game`类集中管理网格状态、分数和游戏结束判定。
2.  **多输入方式融合**：分别监听键盘事件、按钮点击事件和触摸屏的`touchstart`/`touchend`事件。将不同输入（键盘方向键、按钮点击、滑动方向）统一映射为“上、下、左、右”的移动指令，传递给游戏核心逻辑处理。
3.  **响应式与现代化UI**：使用CSS Grid布局构建4x4网格，利用Flexbox进行整体页面自适应布局。通过CSS media queries确保在移动设备上的良好显示。数字方块的颜色将根据数值通过CSS变量动态计算。
4.  **视觉反馈与动画**：使用CSS `transition`和`transform`属性为方块的移动、出现和合并添加平滑动画。通过JavaScript动态添加/移除CSS类来触发动画效果。
5.  **数据持久化**：使用浏览器的`localStorage` API来存储和读取“最高分”记录。

**技术选择理由：**
-   **原生JavaScript**：足够实现游戏逻辑，无框架依赖，体积最小，启动最快。
-   **CSS Grid & Flexbox**：现代CSS标准，完美实现网格布局和响应式。
-   **CSS Transitions**：性能好，实现动画简单高效。
-   **LocalStorage**：无需后端，简单可靠地实现本地数据存储。

    participant M as Main

    Note over M: 初始化阶段
    M->>G: new Game()
    G->>LS: getItem('bestScore')
    LS-->>G: 返回存储的最高分或0
    G->>G: 初始化grid，score=0，bestScore=读取值
    G->>G: addRandomTile() 两次（初始两个数字）
    M->>UI: new UI(G)
    UI->>UI: 根据初始grid构建DOM元素
    UI->>UI: updateScores()
    M->>IH: new InputHandler(G, UI)
    IH->>IH: bindKeyboardEvents()
    IH->>IH: bindButtonEvents()
    IH->>IH: bindTouchEvents()

    Note over IH, UI: 游戏进行阶段（以键盘输入为例）
    IH-->>IH: 用户按下“右箭头”键
    IH->>IH: handleMove('right')
    IH->>G: move('right')
    G->>GL: new GameLogic(currentGrid)
    G->>GL: move('right')
    GL->>GL: 执行移动和合并逻辑
    GL-->>G: 返回 {movedGrid, scoreDelta}
    alt 移动有效（grid发生变化）
        G->>G: 更新grid，累加score
        G->>G: addRandomTile()
        G->>G: 检查游戏是否结束(hasWon/isGameOver)
        G->>G: updateBestScore()
        G->>LS: setItem('bestScore', bestScore)
        G-->>IH: 返回 true
        IH->>UI: updateGrid()
        UI->>UI: 创建/更新所有Tile，添加动画类
        IH->>UI: updateScores()
        alt 游戏胜利(hasWon)
            UI->>UI: showWinAnimation()
        end
        alt 游戏结束(isGameOver)
            UI->>UI: showGameOverMessage()
        end
    else 移动无效
        G-->>IH: 返回 false
        IH->>UI: （可选）播放一个轻微抖动动画提示
    end

    Note over IH, UI: 重新开始游戏
    IH-->>IH: 用户点击“新游戏”按钮
    IH->>IH: handleRestart()
    IH->>G: resetGame()
    G->>G: 重置grid, score
    G->>G: addRandomTile() 两次
    G->>UI: hideGameOverMessage()
    IH->>UI: updateGrid()
    IH->>UI: updateScores()
