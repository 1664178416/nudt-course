## 工具列表

###  GitHub Copilot

**工具名称**  
GitHub Copilot

**支撑软件开发阶段**  
- 编码实现：智能补全、根据自然语言生成代码  
- 代码审查：AI 提供 PR 审查意见  
- 测试辅助：生成测试样例与建议

**工具链接**  
- [GitHub Copilot](https://github.com/features/copilot)

**工具介绍**  
GitHub Copilot 是 GitHub 与 OpenAI 合作推出的 AI 编程助手，支持多种 IDE，能够提高编码效率，通过智能补全和生成测试样例帮助开发者。

**工具评价**  
- **优点**：提高开发效率，支持多语言，适用于各种开发场景。
- **不足**：复杂场景下生成的代码可能需要更多手动调整。

- **不足**：需要订阅，非 JetBrains 环境支持有限。

### Diffblue Cover

**工具名称**  
Diffblue Cover

**支撑软件开发阶段**  
- 单元测试生成：自动生成 JUnit 测试  
- 回归测试：自动更新测试用例  
- CI 集成：自动执行回归测试

**工具链接**  
- [Diffblue Cover](https://www.diffblue.com/)

**工具介绍**  
Diffblue 是一个 Java 单元测试自动生成工具，分析现有代码并生成测试用例，适合缺乏测试覆盖的项目。

**工具评价**  
- **优点**：提高测试覆盖率，支持 CI 集成。
- **不足**：仅支持 Java，无法生成需求层面高质量的测试。
